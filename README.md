# Howie Jennings — Beer League site

V1 static site for GitHub Pages.

## Preview
Open `index.html` in a browser.

## Before launch
Replace every placeholder `href="#"` in `index.html` with the real:
- YouTube video/channel URL
- Pre-save / DSP URLs
- Merch URL
- Instagram
- TikTok
- Facebook

## GitHub Pages
Upload the contents of this folder to a GitHub repository. Once Pages is enabled, connect `howiejennings.com` as the custom domain.
